# Interactive Exploration Canvas

This project runs locally with just a few commands.
These instructions are for people who are new to Terminal.

## Before you start (one-time)

You need Node.js installed on your Mac.

1. Open this link: [https://nodejs.org](https://nodejs.org)
2. Download the **LTS** version.
3. Install it like a normal app (keep clicking Continue).

## Start the website (step by step)

1. Open **Terminal** on your Mac.
   - Press `Command + Space`
   - Type `Terminal`
   - Press `Enter`

2. Copy and paste this command, then press `Enter`:

```bash
cd /Users/yardensalansky/Desktop/potfolio/portfolio_yarden_website
```

3. Install project packages (first time only):

```bash
npm install
```

4. Start the local website:

```bash
npm run dev
```

5. Terminal will show a local URL, usually:
   - `http://localhost:5173`
   - Open that URL in your browser.

## Stop the website

When you are done, click the Terminal window and press:

`Control + C`

## Next time you run the project

You usually only need these 2 commands:

```bash
cd /Users/yardensalansky/Desktop/potfolio/portfolio_yarden_website
npm run dev
```
